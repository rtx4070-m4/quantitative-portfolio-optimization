05. Methodology

Interactive representation of the supplied R workflow.

Data

Historical adjusted prices were downloaded through the R workflow using Yahoo Finance. The supplied stock universe contains 34 tickers across multiple industries.

Returns & Risk

Daily discrete returns are transformed into annualized expected return and volatility using 252 trading days.

Optimization

Top-five stocks by Sharpe Ratio are selected for each horizon, then non-negative fully-invested weights are optimized using quadratic programming.

06. Optimization & Mathematics

Click “Explain” to see a viva-friendly interpretation.

Annualized Expected Return

μ = mean(daily returns) × 252

Annualized Risk

σ = SD(daily returns) × √252

Sharpe Ratio

Sharpe = (μ − Rf) / σ

Optimization Constraints

Σwi = 1    and    wi ≥ 0

Optimization Logic

Maximize (Portfolio Return − Risk-Free Rate) / Portfolio Risk, subject to full investment and no short selling. The R script uses quadratic programming and then removes tiny weights below 0.5% before re-normalizing the remaining weights.
